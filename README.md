# P2-ETF-HJB-STOCHASTIC-CONTROL

A repository for research and implementation of ETF (Exchange-Traded Fund) analysis using Hamilton-Jacobi-Bellman (HJB) equations and stochastic control theory.

## Overview

This project explores the application of optimal stochastic control and HJB equations to ETF portfolio optimization and valuation problems.

## Features

- HJB equation solvers for optimal control problems
- Stochastic control implementation
- ETF portfolio analysis tools
- Numerical methods for PDE solutions

## Getting Started
